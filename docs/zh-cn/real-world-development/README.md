通过真实场景、完整应用程序和共享待办列表，探索 GitHub Copilot 在软件开发生命周期中的应用。你将通过迭代来规划更改、创建代码、测试行为、审查拉取请求，并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构公司，提供面向开发人员的桌游众筹服务。团队的待办列表已整理为 GitHub 议题，供你选择处理。列表包含筛选和分页等功能任务，以及无障碍性和编码标准等质量改进任务。

## 选择开发环境

无论你在哪里工作，都可以使用 GitHub Copilot。请选择适合你的构建方式的环境。每个研讨会都会从单独的设置开始，并使用 Tailspin Toys 共享场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能体式助手。探索 Plan 和 Autopilot 模式、指令、技能、自定义智能体、Playwright MCP、Agent Merge 和实用斜杠命令。

### [GitHub Copilot app][app]

在桌面 app 中运行并行智能体会话、切换会话模式、协作处理画布，以及管理 GitHub 议题和拉取请求。

### [GitHub Copilot 云智能体][cloud]

将 GitHub 议题分配给异步智能体、指导其工作、监视进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。直接在编辑器中使用 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。
